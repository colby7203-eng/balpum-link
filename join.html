📱 안드로이드 앱으로 받을 때
  1. [안드로이드 앱으로 받기] → 받은 파일 누르기 → 설치
  2. 앱을 열면 초대 코드가 저절로 들어가요. 이름 · 핸드폰 · 숫자 6자리만 적으면 끝
🔒 설치가 막힐 때 (보안 경고가 떠요)
  1. “Play 프로텍트에서 차단함”이 뜨면 → [자세히] → [무시하고 설치]
  2. “출처를 알 수 없는 앱”이 뜨면 → [설정] → 이 브라우저(크롬·삼성 인터넷) 허용 켜기 → 뒤로 와서 [설치]
  3. 그래도 막히면 (삼성) 설정 → 보안 및 개인정보 보호 → 자동 차단기 끄기 → 설치 뒤 다시 켜기
  4. 또는 Play 스토어 → 오른쪽 위 내 사진 → Play 프로텍트 → ⚙ → 앱 검사 잠깐 끄기 → 설치 뒤 다시 켜기
발품은 아직 Play 스토어에 올리기 전이라 경고가 떠요. 막히면 위의 1번 바로 쓰기가 제일 쉬워요.
🍎 아이폰
  1. [이 화면에서 바로 쓰기]를 누르면 코드가 들어간 채로 열려요
  2. 이름 · 핸드폰 · 숫자 6자리를 적고 시작
  3. 아래 공유 단추(□↑) → ‘홈 화면에 추가’하면 앱처럼 써요
